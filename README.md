# BOSS直聘自动投递助手

一个 Chrome 浏览器插件（Manifest V3）：登录 BOSS 直聘后，在职位搜索页点击"开始投递"，
插件会自动按你设置的条件搜索匹配的岗位、给 HR 打招呼并完成投递。

## 功能

- 按关键词 / 排除关键词 / 排除公司 / 薪资范围筛选职位
- 自定义打招呼话术
- 自动翻页，直到达到单次投递上限或没有更多职位
- 随机操作间隔，避免过快点击
- 投递记录本地持久化，不会对同一岗位重复打招呼
- 实时进度日志（已投递 / 已跳过 / 异常），关闭弹窗后任务仍在后台继续运行

## 隐私与安全

- 插件**不会**读取、存储或上传你的账号密码、Cookie 或任何登录凭证。
- 所有操作都是在你已登录的浏览器标签页里，模拟人工点击 DOM 元素完成的。
- 已投递 / 已跳过的职位 ID 只保存在你本机的 `chrome.storage.local` 中，不会上传到任何服务器。
- 插件不含任何远程代码、遥测或第三方网络请求。

## ⚠️ 使用须知（务必阅读）

1. **自动化操作可能违反 BOSS 直聘的用户协议**，包括但不限于自动打招呼、批量投递等行为，
   平台可能会因此限制或封禁账号。请自行评估风险，并在使用前查阅 BOSS 直聘的用户协议。
2. 请保持默认或更保守的操作间隔（建议不低于 3~8 秒），单次投递数量不宜设置过大，
   尽量模拟真实用户的操作节奏。
3. 打招呼话术请认真填写，避免群发无意义或不礼貌的信息，这既是对 HR 的基本尊重，
   也能降低被举报 / 限流的概率。
4. 本项目按 MIT 协议开源，不对使用本插件导致的账号限制、纠纷或其他后果负责，
   请谨慎、合规使用。

## 安装（开发者模式加载）

1. 克隆本仓库到本地。
2. 打开 Chrome，访问 `chrome://extensions`。
3. 打开右上角的"开发者模式"。
4. 点击"加载已解压的扩展程序"，选择本项目根目录（包含 `manifest.json` 的目录）。
5. 安装完成后，浏览器工具栏会出现插件图标。

## 使用方法

1. 登录 [BOSS直聘](https://www.zhipin.com) 网页版，进入职位搜索页
   (`https://www.zhipin.com/web/geek/job...`)，按你的意愿设置好城市、职位类别等搜索条件。
2. 点击浏览器工具栏上的插件图标，打开设置面板。
3. 填写关键词、排除条件、期望薪资范围、打招呼话术、单次最多投递数、操作间隔。
4. 点击「开始投递」，插件会在当前页面自动遍历职位卡片、匹配、打招呼、翻页，
   直到达到投递上限或没有更多职位。
5. 可随时点击「停止」中断任务；关闭弹窗不会中断任务，任务在页面后台继续执行，
   重新打开弹窗即可看到最新进度。

## 项目结构

```
.
├── manifest.json              # Chrome 扩展清单 (Manifest V3)
├── src/
│   ├── background/
│   │   └── background.js      # 后台 service worker，缓存并广播任务进度
│   ├── content/
│   │   └── content.js         # 注入到职位搜索页，负责实际的自动化流程
│   ├── popup/
│   │   ├── popup.html         # 设置面板 UI
│   │   ├── popup.css
│   │   └── popup.js           # 读写配置、控制启停、展示日志
│   └── shared/
│       ├── selectors.js       # 集中管理的页面选择器（页面改版时优先改这里）
│       └── matcher.js         # 纯函数：职位是否匹配用户设定的条件
└── test/
    └── matcher.test.js        # 匹配逻辑的单元测试（node --test）
```

## 如果页面结构变化导致插件失效

BOSS 直聘前端会不定期改版。如果发现插件"找不到职位卡片"或"找不到打招呼输入框"等报错：

1. 在职位搜索页按 `F12` 打开开发者工具。
2. 用元素选择工具点击对应的职位卡片 / 打招呼按钮 / 聊天输入框，查看当前的 class 名称。
3. 打开 `src/shared/selectors.js`，把新的选择器加入对应的数组（无需改动其余逻辑）。
4. 回到 `chrome://extensions`，点击插件卡片上的刷新按钮重新加载。
